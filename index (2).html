Section 04 · Quality assurance

Issues found & fixes

!

Dealer name mismatch between site filters and AutoTrader feed

Action needed
What we found

The front-end dealer filter labels do not match the dealer names returned by the AutoTrader feed. In addition, Emond Auto — which is not Subaru-branded — accounts for roughly a third of the listings, so any import or filter logic keyed on the word "Subaru" in the dealer name will silently drop that stock.

Next step

Align the filter labels to the exact feed values and confirm how Emond Auto listings should be treated on the live site.

!

Pagination fix not fully resolved — blog category pages

Action needed
What we found

Carried over. Pagination enhancements were implemented across the blog category pages (People, Tech, Models, Heritage, Travel) to surface the full article list instead of the previous 10-article limit. SEO flagged that the Models category — the site's strongest traffic driver — still isn't displaying correctly: pagination is present, but page 2 onward isn't showing the remaining 140+ articles.

Next step

TO CONFIRM — current status. If still open, correcting the pagination behaviour on the Models category remains a priority given its traffic significance for SEO.

!

Maintenance run — outstanding items

Action needed
Plugin licenses still missing

Carried over — 3 plugins remain outdated pending license keys: Advanced Custom Fields PRO, WP All Export Pro, and WP All Import Pro. Please share current license keys so these can be updated on the next run.
