SubaruSA — Dev

The Black November Deal Assist updates went live on 30 October. Section 03 · Detail

Task details

1

Black November — Deal Assist Updates Live

Live 30 October
The Deal Assist updates for the Black November promotion, focused on the Forester. The offer was revised from R80,000 to R50,000 during the week, with updated creative supplied.

Updated the Deal Assist page to feature only the Forester, replaced all Deal Assist pop-ups with the latest Black November creative for desktop and mobile, removed the Crosstrek pop-up so the pop-up appears only on the Forester page, and updated the homepage banner with the link kept to the same destination. The changes were shared on staging for review. Following the client's feedback, the "Select Your Model" field was removed, as the page now features one vehicle, and the T&Cs copy was updated on the live form at go-live. The client approved, and the updates went live on 30 October.

Deal Assist page
2

Subaru Maintenance :: Web Dev 2/2 (October)

Done
The second of the two October maintenance runs, covering the standard web maintenance checklist — core, plugin and theme updates, backups, and code and API checks. Maintenance has been actioned and the checklist completed. The monthly form checks have also been completed, with the sales form submissions tested as part of the Book a Test Drive fix.

Web maintenance checklist
3

Book a Test Drive Form — Vehicle Model Tracking

Resolved
The vehicle model was not coming through on some Book a Test Drive submissions, so sales consultants could not see which vehicle the customer was interested in.

The affected submission was traced, the form was checked across the vehicle pages, and the issue preventing the model from being captured was fixed. All the Book a Test Drive sales forms were then tested, confirming the vehicle model now comes through with each lead, so sales consultants can see which vehicle the customer is enquiring about.
Test submission — vehicle model coming through
4

Garmin MTB Classic (CPT) — Event Removed

Done
With the Garmin MTB Classic (CPT) event now wrapped up, it was taken off the Subaru website.

Removed the event from the homepage and from the events page, which now shows that there are no current events.

Outback Imagery & Pricing Updates

Section 04 · Quality assurance

Issues found & fixes

!

Vehicle model missing from Book a Test Drive submissions

Resolved
What we found

Some Book a Test Drive submissions were coming through without the vehicle model, so sales consultants could not see which vehicle the customer was enquiring about.

Fix

The form was fixed and all the Book a Test Drive sales forms were tested, and the vehicle model now comes through with every submission.

!

Pre-Owned leads not reaching dealerships

In testing
What we found

The Pre-Owned lead form is grouped with the Contact Us form in tracking, the vehicle of interest is not captured correctly, and leads are not reaching the dealerships.

Next step

The fix has been implemented and is currently in testing.

!

Forms register change alerts not yet triggering

Action needed
What we found

Changes made to the live email list did not send a notification to the team, so the automated change alerts are not yet working as intended.

Next step

The alerts are being finalised and tested alongside the Register Your Interest form updates from the client's feedback, so the team is notified whenever the register is updated.
